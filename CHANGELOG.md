# Changelog

All notable changes to this repository are recorded here.

- Released the paper-faithful executable reimplementation for both reported SSVEP datasets.

- Added matched clean-baseline and scenario-specific adversarial-training workflows.
- Added frozen publication inputs, comparison analysis, figure generation, provenance records, scientific tests, and smoke validation.
- Added complete installation, PyCharm, data-license, result-schema, and reproducibility documentation.
